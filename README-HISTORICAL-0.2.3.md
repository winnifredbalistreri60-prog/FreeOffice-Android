# Свободный офис для Android — 0.2.0 P0 alpha

Бесплатное автономное приложение с русским интерфейсом. Без подписки, рекламы, регистрации и сервера обработки. Разрешения INTERNET в манифесте нет. Минимум Android 8.0; ABI arm64-v8a и x86_64.

## Главное в этой сборке

XLS/XLSX открываются в отдельном разреженном просмотрщике: листы, поиск, адрес ячейки, полный текст и копирование. Окно 40×10 не усекáет принятую книгу и не ограничивает просмотр лимитом редактора 2000×200. Оформление исходного Excel-файла не воспроизводится точно.

Для таблиц добавлены pinch, видимые +/− и «По ширине области». Меняются одновременно текст, размеры ячеек и заголовков. Подгонка относится только к текущему окну столбцов, не к целому листу; маленький масштаб — обзорный. При изменении масштаба код сохраняет лист, адрес выделения, область данных и координатный якорь прокрутки с ограничением у краёв. Окончательная проверка поведения жестов назначена DroidDeck Tester.

PDF отображается системным PdfRenderer на отдельном последовательном worker: страницы, переход к номеру, pinch, +/−, подгонка по ширине, перемещение по двум осям. При увеличении запрашивается новый растр. Буфер ограничен 8 млн пикселей и стороной 4096; при достижении предела показывается предупреждение. Это не тайловый PDF-движок; редактирования, OCR, подписей, ввода пароля и PDF→DOCX нет.

TXT открывается для чтения с переносом по ширине; редактирование копии включается отдельно. TXT/CSV/TSV имеют выбор UTF-8, Windows-1251, UTF-16LE/BE, BOM и окончаний строк при экспорте. Для CSV доступны запятая, точка с запятой и табуляция; TSV записывается с табуляцией. Автоопределение разделителя — эвристика, при сомнении задайте его вручную и проверьте предпросмотр. Основная кнопка «Открыть» действительно открывает файл в просмотрщике, не только предпросмотр.

CSV/TSV импортируют все поля строками: без автоматического преобразования 00123, дат или =формул. Кавычки, удвоенные кавычки и переводы строк внутри полей разбираются; ошибочная структура отклоняется явно. При конвертации CSV/TSV в XLSX поля тоже сохраняются строками. Защита от интерпретации формул другими программами — отдельная опция экспорта, которая намеренно добавляет апостроф и меняет значения.

## Редактирование и сохранение

«Просмотр», «Редактировать копию», «Сохранить копию» и «Экспорт» разделены. Исходник автоматически не перезаписывается. При выборе SAF-документа, совпадающего с исходником по URI/идентификатору, запись блокируется; выбирайте новое имя файла. Это не транзакционная гарантия поведения стороннего файлового провайдера. После ошибки записи новая копия может быть неполной, но данные остаются в редакторе.

Редактор таблицы показывает начальную область до 40 строк и 12 столбцов; любую принятую ячейку можно изменить отдельно по адресу. Данные вне области не удаляются. Нативный редактор/экспорт XLSX ограничен 2000 строками, 200 столбцами и 100000 ячейками на книгу. Для текстовых таблиц доступно больше данных через отдельный кодек, но конвертация в XLSX по-прежнему ограничена мостом. Формулы локально не пересчитываются.

Локальный рабочий черновик записывается атомарно после паузы ввода и при уходе в фон. Хранится один черновик до 16 МБ; восстановление предлагается на главной странице. Перед началом другой рабочей копии существующий черновик защищён подтверждением. Это не история версий и не гарантия сохранения последних нажатий при аварии или нехватке памяти. После экспорта другого формата/одного листа состояние изменённой книги не сбрасывается ошибочно в «сохранено».

## Остальные форматы и пределы

DOCX/ODT: только извлечённый текст и упрощённые копии. Нет полноценной вёрстки страниц, изображений, таблиц, комментариев и колонтитулов; жирный/курсив DOCX экспортируются по абзацам. ODT сохраняет только текст. PPTX/ODP: только текст слайдов, не визуальные слайды и не редактирование. DOC/DOTX/RTF/PPT/XLSB/XLSM и макросы в этой сборке не заявлены. Подробности — [FORMATS.md](FORMATS.md).

Входной файл — до 32 МБ. TXT/CSV/TSV — до 2000000 символов; CSV/TSV дополнительно до 20000 строк, 512 столбцов, 500000 полей. Лимиты и ошибки не должны скрыто усекать данные. Проверяйте важные результаты в другом редакторе и сохраняйте оригиналы.

## Исходные проекты и лицензии

[WordCraft](https://github.com/storytold/wordcraft): модель документа и DOCX. [GridCraft](https://github.com/storytold/gridcraft): XLS/XLSX и модель книги. [PdfCraft](https://github.com/storytold/pdfcraft): библиотека разбора PDF; экран PDF использует Android PdfRenderer. Это независимая мобильная производная работа, не официальный релиз ArtCraft.

Собственный код — MIT. Исходные лицензии и уведомления WordCraft/GridCraft/PdfCraft и транзитивных Rust-зависимостей находятся в `app/src/main/assets/licenses/` и в «О проекте → Лицензии». Новых платных SDK или внешних библиотек в P0 не добавлено.

## Сборка и статус проверок

Нужны JDK 17+, SDK 35, NDK 27.3.13750724, Rust и Android-цели aarch64-linux-android/x86_64-linux-android. Укажите SDK в local.properties и upstream-пути в native/Cargo.toml; ревизии — UPSTREAM-REVISIONS.txt.

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk native/build-android.sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это debug-подпись для ручной установки, не публикация в магазине. Компиляция и Lint — статические проверки, не тестирование приложения. Запуск APK и функциональные проверки выполняет только назначенный DroidDeck Tester. Разработчик приложение не запускал.
