# Статус первой alpha-сборки

- Native host: cargo check пройден.
- Native Android: обе библиотеки после исправлений скомпилированы для arm64-v8a и x86_64, NDK API 26.
- Java: компиляция после подключения современных форматов пройдена.
- Финальная сборка APK и Android Lint: результат записан в build-final.log рабочего проекта; передача выполняется только после успешной сборки.
- Функциональные, UI, инструментальные и round-trip тесты разработчиком не запускались по прямому требованию пользователя. Наличие функций в интерфейсе не является результатом тестирования.
- Для независимого тестировщика: используйте только итоговый APK /workspace/freeoffice-delivery/freeoffice-0.1.0-alpha-debug.apk и синтетические документы. Более ранние app-debug.apk были промежуточными и могли содержать прежний JNI-мост.
- План и начальные синтетические файлы: /workspace/freeoffice-qa/PLAN.md и /workspace/freeoffice-qa/fixtures/. Для нового набора форматов тестировщику нужны дополнительные ODT/ODS/ODP/PPTX/CSV/TSV примеры.
- Проверить отдельно: кириллицу и emoji; XLS импорт; сохранение копии; отсутствие смещения непустых данных из C5 в A1; отказ вместо обрезки больших книг; ODS повторённые строки; порядок слайдов PPTX и группировку слайдов ODP; ошибки повреждённых файлов; отсутствие сети/оплаты.

Приложение остаётся alpha-версией. Локального пересчёта формул нет; ODT сохраняет только текст; PPTX/ODP — только извлечение текста, без редактирования/сохранения презентаций. Точные режимы описаны в FORMATS.md.
